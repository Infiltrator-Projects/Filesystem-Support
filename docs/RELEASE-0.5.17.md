# Filesystem Support 0.5.17

Release 0.5.17 consolidates the control-plane, qualification and brittleness-reduction work already present on `main`.

The release retains the single-package Debian design, per-filesystem desktop integration ownership, fail-closed package-removal confirmation, truthful probe-state handling, trusted privileged executable resolution, native-module rollback verification, Windows EXT2 code analysis, sanitizer/adversarial qualification and Amiga runtime/crash-recovery qualification.

This file is the release marker for the exact source tree published as 0.5.17.
